# Пользовательский API

Публичный API AlterCPA TOP позволяет управлять ботами и кампаниями, получать статистику,
экспортировать лиды и работать с оплатой — всё программно. API предоставляет **тот же
интерфейс, что использует дашборд**, поэтому всё, что можно сделать в UI, можно и
автоматизировать.

**Базовый URL:** `https://my.altercpa.top/api`

## Быстрый старт

```bash
curl "https://my.altercpa.top/api/profile/info.json?id=42-d3adb33f…"
```

```json
{ "status": "ok", "data": { "id": 42, "name": "John Doe", … } }
```

Замените `42-d3adb33f…` на ваш ключ `{user_id}-{user_api}` из
[Профиль → API-ключ](https://docs.altercpa.top/ru/guide/profile/). Подробнее об аутентификации и структуре
ответов — в разделе [Авторизация и соглашения](authentication.md).
