## Что это

[AlterCPA TOP](https://www.altercpa.top) (Telegram Optimisation Platform) отслеживает вступления в ваши
Telegram-каналы и группы через бота и передаёт каждое как CPA-постбек в трекер рекламодателя —
AlterCPA Lite, AlterCPA Pro, Keitaro, Binom или собственный. Это **скилл** для [Claude](https://claude.com), который
обучает его пользовательскому API TOP. Просто опишите задачу — скрипт, интеграцию или отчёт — и Claude
напишет запросы с правильными методами, параметрами и обработкой ошибок, а не будет угадывать.

> Этот скилл — для **API сервиса TOP** (`my.altercpa.top/api`), а не для API вашего трекера.
> У трекера AlterCPA Lite есть свой скилл: [skill-lite](https://github.com/altercpa/skill-lite).

## Что умеет

| Область | Что можно делать |
|---|---|
| **Профиль и трекер** | данные аккаунта, смена ключа API, глобальные шаблоны постбеков, уведомления и язык, подключение трекера AlterCPA Lite |
| **Боты** | подключение и отключение Telegram-ботов, профиль и аватар бота, чаты, где бот администратор, кампания по умолчанию |
| **Кампании, экраны, медиа** | CRUD кампаний, deep link, пауза и возобновление, потоки трекера, приветственные экраны с кнопками, загрузка медиа, защита CAS, очистка группы |
| **Рассылки** | триггерные дожимы по статусам лидов; ручные массовые рассылки: создание, запуск, пауза, возобновление, отмена |
| **CRM: команды и операторы** | команды, операторы, шаблоны ответов, пользовательские события, статистика CRM, надзор за диалогами |
| **Лиды, журнал, статистика** | лиды и счётчики по статусам, журнал активности чатов, сводная и сгруппированная статистика, выгрузки в CSV |
| **Передача** | передача бота со всеми кампаниями или отдельной кампании другому аккаунту |
| **Тарифы и биллинг** | тарифы, платежи (создание, продолжение, отмена, проверка), история платежей |

## Установка

### Claude Code

Скачайте [`altercpa-top-api-skill.zip`](https://github.com/altercpa/skill-top/releases/latest/download/altercpa-top-api-skill.zip)
и распакуйте в папку скиллов:

```sh
unzip altercpa-top-api-skill.zip -d ~/.claude/skills/      # для всех проектов
unzip altercpa-top-api-skill.zip -d .claude/skills/        # только для этого проекта
```

В Windows распакуйте в `%USERPROFILE%\.claude\skills\`.

Предпочитаете git? Клонируйте прямо в папку скиллов — обновление сводится к `git pull`:

```sh
git clone https://github.com/altercpa/skill-top.git ~/.claude/skills/altercpa-top-api
```

### Claude.ai и Claude Desktop

В настройках Claude добавьте собственный скилл и загрузите тот же zip.

## Как пользоваться

Вызывать ничего не нужно — Claude подключает скилл сам, когда запрос касается API AlterCPA TOP.
Например:

- *Создай кампанию для моего бота и дай её deep link.*
- *Напиши скрипт на Python, который выгружает вчерашние лиды из AlterCPA TOP в CSV.*
- *Покажи список моих подключённых ботов.*
- *Настрой рассылку для подписчиков моей кампании и запусти её.*

Большинство вызовов устроено одинаково; ключ — это `{user_id}-{user_api}` из профиля в кабинете TOP:

```
https://my.altercpa.top/api/{area}/{func}.json?id={key}
```

Вызовы со своим параметром `id` (например, `camp/get`) передают ключ заголовком `Authorization: Bearer {user_api}`.
Несколько путей устроены иначе — у CRM три сегмента, у `pay/*` нет `.json` — все они перечислены в `SKILL.md`.
